一、概述与背景

1.1 Android Camera API 演进历史

Android Camera API 演进
├─ Camera1 API (Android 1.0+)
│ ├─ 2008年：初始版本发布
│ ├─ 特点：简单易用，同步阻塞式
│ └─ 局限：功能受限，性能瓶颈
├─ Camera2 API (Android 5.0+)
│ ├─ 2014年：Lollipop引入
│ ├─ 特点：异步非阻塞，Pipeline架构
│ └─ 优势：高性能，细粒度控制
└─ CameraX (Android Jetpack)
├─ 2019年：高级封装库
├─ 特点：简化开发，自动兼容
└─ 底层：基于Camera2实现
💡 为什么需要Camera2？
  • 性能需求：Camera1的同步模型导致UI线程阻塞，无法满足高帧率、低延迟需求
  • 功能扩展：RAW格式、手动控制、连拍、HDR等高级功能难以在Camera1上实现
  • 硬件演进：多摄像头、高分辨率传感器需要更精细的控制
  • 架构设计：HAL3硬件抽象层的引入，需要新的API适配

1.2 Camera1 vs Camera2 核心差异

对比维度 Camera1 API Camera2 API
API设计 同步阻塞式，简单直观 异步非阻塞，Pipeline管道
调用模型 直接方法调用 请求-响应模式
参数配置 Parameters键值对 CaptureRequest + Metadata
会话管理 无会话概念 CaptureSession管理
多摄像头 不支持 原生支持
RAW格式 不支持 支持RAW/YUV/JPEG
手动控制 有限支持 完全手动控制
性能 低，易阻塞UI 高，充分利用硬件
学习曲线 简单 陡峭，概念复杂
维护状态 已弃用（Deprecated） 推荐使用

二、Camera1 API 详解

2.1 概念与特点

核心概念

Camera1 API 是 Android 最早引入的相机接口，基于 android.hardware.Camera 类实现。其设计理念简单直接：一个 Camera 对象代表一个物理摄像头设备。

Camera1 API 核心组件
├─ Camera（核心类）
│ ├─ open() - 打开摄像头
│ ├─ release() - 释放资源
│ └─ setPreviewDisplay() - 设置预览
├─ Camera.Parameters（参数配置）
│ ├─ 预览尺寸
│ ├─ 图片尺寸
│ ├─ 对焦模式
│ ├─ 闪光灯模式
│ └─ 场景模式
├─ 回调接口
│ ├─ PreviewCallback - 预览数据回调
│ ├─ PictureCallback - 拍照数据回调
│ ├─ AutoFocusCallback - 对焦回调
│ └─ ErrorCallback - 错误回调
└─ CameraInfo（设备信息）
├─ facing - 前置/后置
├─ orientation - 设备方向
└─ canDisableShutterSound - 静音支持
⚠️ Camera1 已被标记为 Deprecated

从 Android 5.0 开始，Google 官方推荐使用 Camera2 API。Camera1 仍可使用但不再积极维护，新项目应优先选择 Camera2 或 CameraX。

2.2 核心机制与实现原理

工作原理

Camera1 采用同步调用模型，其核心流程如下：

Camera1 工作流程
1. 打开摄像头
└─ Camera.open(cameraId)
2. 配置参数
├─ getParameters()
├─ 修改参数对象
└─ setParameters(params)
3. 设置预览
├─ setPreviewDisplay(holder)
├─ setPreviewCallback(callback)
└─ startPreview()
4. 拍照
├─ autoFocus(callback)
└─ takePicture(shutter, raw, jpeg)
5. 释放资源
├─ stopPreview()
└─ release()

底层实现机制

Camera1 Native 层调用链
// Java 层 Camera.java
public class Camera {
    private native final void native_setup(Object camera_this, 
                                                  int cameraId, 
                                                  String packageName);
    private native final void native_release();

    private native final void native_takePicture(int msgType);

}

// Native 层 android_hardware_Camera.cpp
static void android_hardware_Camera_native_setup(JNIEnv *env, 
                                                       jobject thiz, 
                                                       int cameraId) {
    // 创建 Camera 客户端
    sp<Camera> camera = Camera::connect(cameraId);
    
    // 设置回调监听
    camera->setListener(listener);
}

// Framework 层 Camera.cpp
sp<Camera> Camera::connect(int cameraId) {
    // 通过 Binder IPC 连接 CameraService
    sp<ICamera> c = cs->connect(callbacks, cameraId, packageName);
    return camera;
}
🔍 关键实现细节
  • Binder IPC：应用层通过 Binder 与系统服务 CameraService 通信
  • 同步阻塞：大多数方法调用会阻塞等待 HAL 层响应
  • 单线程模型：默认在调用线程执行，容易阻塞 UI
  • 回调通知：通过 Looper 机制将回调分发到应用层

⚠️ 生命周期管理注意事项
  • Activity生命周期绑定：必须在 onResume() 打开相机，在 onPause() 释放资源

  • 状态检查：每次调用前检查 mCamera 是否为 null

2.6 应用场景与最佳实践

适用场景

  • 简单拍照应用：对性能要求不高的基础拍照功能
  • 兼容老设备：需要支持 Android 4.4 及以下版本
  • 快速原型：开发阶段的快速验证
✅ Camera1 最佳实践
  • 始终在后台线程打开相机，避免阻塞 UI
  • 使用 HandlerThread 处理相机回调
  • 合理选择预览和拍照尺寸，避免内存溢出
  • 及时释放资源，防止资源泄漏

三、Camera2 API 详解

3.1 概念与特点

Camera2 API 是 Android 5.0 引入的全新相机架构，基于 HAL3（Hardware Abstraction Layer 3）实现，采用异步非阻塞的 Pipeline 设计，支持手动控制、RAW 格式、多摄像头等高级功能。

🔑 Camera2 核心特性
  • Pipeline 架构：请求-处理-结果的流水线模式，可并行处理多个请求
  • 异步非阻塞：所有操作通过回调异步返回，不会阻塞主线程
  • Metadata 驱动：通过元数据精细控制每一帧的参数
  • 多流输出：同时输出多个 Surface（预览+拍照+录像）
  • RAW 支持：访问原始传感器数据，支持 DNG 格式
  • 手动控制：完全手动控制对焦、曝光、ISO、白平衡

关于 Camera2 的更多详细内容，包括：

  • HAL3 Pipeline 架构详解
  • CaptureSession 会话管理
  • CaptureRequest/Result Metadata 机制
  • 3A 算法（AF/AE/AWB）实现原理
  • ISP 图像处理 Pipeline
  • Buffer 管理与分发机制
  • 手动模式实现
  • 多摄像头支持

请参考 官方 Camera HAL 文档 和相关技术资料。

硬件支持级别

级别 描述 主要特性
LEGACY 向后兼容模式 仅支持 Camera1 的功能，通过适配层实现
LIMITED 有限支持 基本的 Camera2 功能，部分手动控制
FULL 完全支持 支持所有 Camera2 功能，完全手动控制
LEVEL_3 增强支持 YUV 重处理、RAW 图像捕获
检查设备硬件支持级别
private void checkHardwareLevel(String cameraId) {
    try {
        CameraManager manager = (CameraManager) 
            getSystemService(Context.CAMERA_SERVICE);
        CameraCharacteristics characteristics = 
            manager.getCameraCharacteristics(cameraId);
        
        // 获取硬件支持级别
        Integer level = characteristics.get(
            CameraCharacteristics.INFO_SUPPORTED_HARDWARE_LEVEL);
        
        String levelName;
        switch (level) {
            case CameraCharacteristics.INFO_SUPPORTED_HARDWARE_LEVEL_LEGACY:
                levelName = "LEGACY";
                break;
            case CameraCharacteristics.INFO_SUPPORTED_HARDWARE_LEVEL_LIMITED:
                levelName = "LIMITED";
                break;
            case CameraCharacteristics.INFO_SUPPORTED_HARDWARE_LEVEL_FULL:
                levelName = "FULL";
                break;
            case CameraCharacteristics.INFO_SUPPORTED_HARDWARE_LEVEL_3:
                levelName = "LEVEL_3";
                break;
            default:
                levelName = "UNKNOWN";
        }
        
        Log.d("Camera2", "Hardware Level: " + levelName);
        
    } catch (CameraAccessException e) {
        e.printStackTrace();
    }
}

3.2 Camera2 完整工作流程示例

Camera2 完整实现示例
public class Camera2Activity extends AppCompatActivity {
    
    private CameraManager mCameraManager;
    private CameraDevice mCameraDevice;
    private CameraCaptureSession mCaptureSession;
    private TextureView mTextureView;
    private ImageReader mImageReader;
    
    private HandlerThread mBackgroundThread;
    private Handler mBackgroundHandler;
    
    // 1. 初始化
    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_camera2);
        
        mTextureView = findViewById(R.id.textureView);
        mCameraManager = (CameraManager) 
            getSystemService(Context.CAMERA_SERVICE);
        
        // 设置 TextureView 监听器
        mTextureView.setSurfaceTextureListener(mSurfaceTextureListener);
    }
    
    // 2. 启动后台线程
    @Override
    protected void onResume() {
        super.onResume();
        startBackgroundThread();
        
        if (mTextureView.isAvailable()) {
            openCamera();
        }
    }
    
    private void startBackgroundThread() {
        mBackgroundThread = new HandlerThread("CameraBackground");
        mBackgroundThread.start();
        mBackgroundHandler = new Handler(mBackgroundThread.getLooper());
    }
    
    // 3. 打开相机
    private void openCamera() {
        try {
            String cameraId = mCameraManager.getCameraIdList()[0];
            
            // 检查权限
            if (ActivityCompat.checkSelfPermission(this, 
                Manifest.permission.CAMERA) != PackageManager.PERMISSION_GRANTED) {
                return;
            }
            
            // 打开相机
            mCameraManager.openCamera(cameraId, mStateCallback, mBackgroundHandler);
            
        } catch (CameraAccessException e) {
            e.printStackTrace();
        }
    }
    
    // 4. 相机状态回调
    private final CameraDevice.StateCallback mStateCallback = 
        new CameraDevice.StateCallback() {
        
        @Override
        public void onOpened(CameraDevice camera) {
            mCameraDevice = camera;
            createCameraPreviewSession();
        }
        
        @Override
        public void onDisconnected(CameraDevice camera) {
            camera.close();
            mCameraDevice = null;
        }
        
        @Override
        public void onError(CameraDevice camera, int error) {
            camera.close();
            mCameraDevice = null;
        }
    };
    
    // 5. 创建预览 Session
    private void createCameraPreviewSession() {
        try {
            // 准备预览 Surface
            SurfaceTexture texture = mTextureView.getSurfaceTexture();
            texture.setDefaultBufferSize(1920, 1080);
            Surface previewSurface = new Surface(texture);
            
            // 准备 ImageReader（拍照用）
            mImageReader = ImageReader.newInstance(
                1920, 1080, ImageFormat.JPEG, 2);
            mImageReader.setOnImageAvailableListener(
                mOnImageAvailableListener, mBackgroundHandler);
            
            // 创建 Session
            mCameraDevice.createCaptureSession(
                Arrays.asList(previewSurface, mImageReader.getSurface()),
                new CameraCaptureSession.StateCallback() {
                    @Override
                    public void onConfigured(CameraCaptureSession session) {
                        mCaptureSession = session;
                        startPreview();
                    }
                    
                    @Override
                    public void onConfigureFailed(CameraCaptureSession session) {
                        Log.e("Camera2", "Session configuration failed");
                    }
                },
                mBackgroundHandler
            );
            
        } catch (CameraAccessException e) {
            e.printStackTrace();
        }
    }
    
    // 6. 启动预览
    private void startPreview() {
        try {
            // 创建预览请求
            CaptureRequest.Builder builder = mCameraDevice
                .createCaptureRequest(CameraDevice.TEMPLATE_PREVIEW);
            
            Surface previewSurface = new Surface(mTextureView.getSurfaceTexture());
            builder.addTarget(previewSurface);
            
            // 设置 3A 模式
            builder.set(CaptureRequest.CONTROL_AF_MODE,
                CaptureRequest.CONTROL_AF_MODE_CONTINUOUS_PICTURE);
            builder.set(CaptureRequest.CONTROL_AE_MODE,
                CaptureRequest.CONTROL_AE_MODE_ON_AUTO_FLASH);
            builder.set(CaptureRequest.CONTROL_AWB_MODE,
                CaptureRequest.CONTROL_AWB_MODE_AUTO);
            
            // 发送重复请求
            mCaptureSession.setRepeatingRequest(
                builder.build(), mCaptureCallback, mBackgroundHandler);
            
        } catch (CameraAccessException e) {
            e.printStackTrace();
        }
    }
    
    // 7. 拍照
    public void takePicture() {
        try {
            CaptureRequest.Builder builder = mCameraDevice
                .createCaptureRequest(CameraDevice.TEMPLATE_STILL_CAPTURE);
            
            builder.addTarget(mImageReader.getSurface());
            
            // 设置 JPEG 参数
            int rotation = getWindowManager().getDefaultDisplay().getRotation();
            builder.set(CaptureRequest.JPEG_ORIENTATION, getJpegOrientation(rotation));
            builder.set(CaptureRequest.JPEG_QUALITY, (byte) 95);
            
            // 捕获
            mCaptureSession.capture(builder.build(), 
                mCaptureCallback, mBackgroundHandler);
            
        } catch (CameraAccessException e) {
            e.printStackTrace();
        }
    }
    
    // 捕获回调
    private final CameraCaptureSession.CaptureCallback mCaptureCallback =
        new CameraCaptureSession.CaptureCallback() {
        
        @Override
        public void onCaptureCompleted(CameraCaptureSession session,
                                       CaptureRequest request,
                                       TotalCaptureResult result) {
            // 获取捕获结果
            Long exposureTime = result.get(CaptureResult.SENSOR_EXPOSURE_TIME);
            Integer iso = result.get(CaptureResult.SENSOR_SENSITIVITY);
            
            Log.d("Camera2", "Exposure: " + exposureTime + "ns, ISO: " + iso);
        }
    };
    
    // 图像可用监听器
    private final ImageReader.OnImageAvailableListener mOnImageAvailableListener =
        reader -> {
            Image image = reader.acquireLatestImage();
            if (image != null) {
                // 保存图片
                saveImage(image);
                image.close();
            }
        };
    
    // 8. 资源释放
    @Override
    protected void onPause() {
        closeCamera();
        stopBackgroundThread();
        super.onPause();
    }
    
    private void closeCamera() {
        if (mCaptureSession != null) {
            mCaptureSession.close();
            mCaptureSession = null;
        }
        if (mCameraDevice != null) {
            mCameraDevice.close();
            mCameraDevice = null;
        }
        if (mImageReader != null) {
            mImageReader.close();
            mImageReader = null;
        }
    }
    
    private void stopBackgroundThread() {
        mBackgroundThread.quitSafely();
        try {
            mBackgroundThread.join();
            mBackgroundThread = null;
            mBackgroundHandler = null;
        } catch (InterruptedException e) {
            e.printStackTrace();
        }
    }
}
✅ Camera2 最佳实践
  • 独立线程：始终使用 HandlerThread 处理相机操作
  • 检查支持：通过 CameraCharacteristics 检查功能支持
  • 资源管理：按顺序关闭 Session → Device → ImageReader
  • 错误处理：实现所有回调的错误处理逻辑
  • 生命周期：在 onResume 打开、onPause 关闭
