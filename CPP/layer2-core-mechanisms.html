🔧 2.1 函数模板机制

基础语法

template<typename T>
T max(const T& a, const T& b) {
    return (a > b) ? a : b;
}

// 使用：编译器自动推导类型
int i = max(3, 7);  // max<int>

参数推导规则

参数形式推导规则示例
T忽略顶层constconst int& → int
T&保留constconst int& → const int
T&&万能引用左值→T&，右值→T
💡 完美转发 使用T&&和std::forward<T>实现完美转发，保持参数的值类别。

📦 2.2 类模板机制

template<typename T>
class Stack {
    std::vector<T> elements;
public:
    void push(const T& elem) { 
        elements.push_back(elem); 
    }
    T top() const { 
        return elements.back(); 
    }
};

Stack<int> s;  // 实例化Stack<int>

延迟实例化

类模板的成员函数只有在被调用时才会实例化，这允许某些成员对某些类型无效。

成员函数模板

template<typename T>
class Container {
public:
    template<typename U>
    Container& operator=(const Container<U>& other) {
        // 泛型赋值
        return *this;
    }
};

🎯 2.5 模板特化机制

// 主模板
template<typename T, typename U>
class MyClass { /* 通用实现 */ };

// 全特化
template<>
class MyClass<int, double> { /* int-double特化 */ };

// 偏特化（指针类型）
template<typename T>
class MyClass<T*, T*> { /* 指针特化 */ };

匹配优先级

  1. 全特化（最高优先级）
  2. 偏特化（次优先级，选最特化的）
  3. 主模板（默认）
