🔤 4.0 C++类型系统基础

模板技术建立在C++类型系统之上，深入理解类型系统是掌握模板的基础。

类型分类体系

📚 类型层次结构
C++类型系统分为三大类：
  • 基本类型：void, nullptr_t, 算术类型（整型、浮点型）
  • 复合类型：指针、引用、数组、函数、成员指针
  • 用户定义类型：类、枚举、联合体

CV限定符

// const和volatile限定符
const int ci = 42;          // top-level const
const int* pci = &ci;      // low-level const (指向const的指针)
int* const cpi = nullptr;  // top-level const (const指针)

// 模板中的CV推导
template<typename T>
void func(T param) {  // T会忽略顶层const
    // const int传入，T推导为int
}

template<typename T>
void func_ref(T& param) {  // T&保留const
    // const int&传入，T推导为const int
}

值类别系统 (Value Category)

C++11引入五种值类别，这是理解移动语义和完美转发的关键。

值类别定义特征典型例子
lvalue 有名字的对象或返回左值引用的表达式 可以取地址、可出现在赋值左侧 变量名、*ptr、返回T&的函数
prvalue 纯右值，临时对象或字面量 不能取地址、即将被销毁 字面量42、返回T的函数、Lambda
xvalue 将亡值，生命周期即将结束的对象 可以被移动 std::move(x)、返回T&&的函数
glvalue 泛左值 = lvalue + xvalue 有内存位置 所有lvalue和xvalue
rvalue 右值 = prvalue + xvalue 可出现在赋值右侧 所有prvalue和xvalue 
// 值类别示例
int x = 10;           // x是lvalue，10是prvalue
int& rx = x;         // rx是lvalue
int&& rrx = 20;      // rrx是lvalue（名字），20是prvalue
int&& rrx2 = std::move(x);  // std::move(x)是xvalue

// 判断值类别
&x;                   // OK，lvalue可以取地址
// &10;               // 错误，prvalue不能取地址
&std::move(x);      // OK，xvalue可以取地址

类型推导规则对比

推导方式引用处理CV限定符数组/函数退化
auto auto&保留引用 auto忽略顶层const 会退化
decltype(expr) 完全保留 完全保留 不退化
decltype(auto) 保留值类别 保留CV 不退化
模板T T&不退化，T退化 忽略顶层const T会退化，T&不会 
// 类型推导对比
const int ci = 42;
const int& rci = ci;

auto a1 = ci;          // a1: int (丢失const)
auto& a2 = ci;         // a2: const int&
decltype(ci) d1 = ci; // d1: const int
decltype((ci)) d2 = ci; // d2: const int& (表达式是lvalue)
decltype(auto) d3 = ci; // d3: const int

// 数组退化
int arr[10];
auto a = arr;          // a: int* (退化为指针)
auto& r = arr;         // r: int(&)[10] (保持数组)
decltype(arr) d = arr; // d: int[10] (保持数组)

引用折叠规则

引用折叠是完美转发的基础，理解这个规则至关重要。

原始类型T& &T& &&T&& &T&& &&
折叠结果 T& T& T& T&&

规则：只有 && && 折叠为 &&，其他都折叠为 &

// 引用折叠应用
template<typename T>
void wrapper(T&& param) {  // 万能引用
    // 传入lvalue: T推导为int&, T&& & 折叠为 int&
    // 传入rvalue: T推导为int, T&& && 折叠为 int&&
}

int x = 10;
wrapper(x);   // T = int&, param类型为int&
wrapper(10);  // T = int, param类型为int&&

🧠 4.1 模板元编程 (TMP)

模板元编程的核心理念：将计算从运行期转移到编译期，实现零运行时开销。

编译期计算

// 编译期阶乘计算
template<int N>
struct Factorial {
    static constexpr int value = N * Factorial<N-1>::value;
};

template<>
struct Factorial<0> {
    static constexpr int value = 1;
};

// 使用
constexpr int result = Factorial<5>::value;  // 编译期计算：120

// 斐波那契数列
template<int N>
struct Fibonacci {
    static constexpr int value = Fibonacci<N-1>::value + Fibonacci<N-2>::value;
};

template<> struct Fibonacci<0> { static constexpr int value = 0; };
template<> struct Fibonacci<1> { static constexpr int value = 1; };

类型计算

// 类型萌取：移除const
template<typename T>
struct remove_const {
    using type = T;
};

template<typename T>
struct remove_const<const T> {
    using type = T;
};

// 使用
using Type1 = remove_const<const int>::type;  // int
using Type2 = remove_const<int>::type;        // int

// 移除引用
template<typename T> struct remove_reference      { using type = T; };
template<typename T> struct remove_reference<T&>  { using type = T; };
template<typename T> struct remove_reference<T&&> { using type = T; };

// 类型选择 (std::conditional)
template<bool Condition, typename TrueType, typename FalseType>
struct conditional {
    using type = TrueType;
};

template<typename TrueType, typename FalseType>
struct conditional<false, TrueType, FalseType> {
    using type = FalseType;
};

// 应用：选择更大的类型
template<typename T, typename U>
using larger_type = typename conditional<
    (sizeof(T) > sizeof(U)), T, U
>::type;

编译期数据结构

// 类型列表
template<typename... Types>
struct TypeList {};

// 获取第一个类型
template<typename List>
struct Front;

template<typename Head, typename... Tail>
struct Front<TypeList<Head, Tail...>> {
    using type = Head;
};

// 列表长度
template<typename List>
struct Length;

template<typename... Types>
struct Length<TypeList<Types...>> {
    static constexpr size_t value = sizeof...(Types);
};

// 使用
using MyList = TypeList<int, double, char>;
using First = Front<MyList>::type;  // int
constexpr size_t len = Length<MyList>::value;  // 3
💡 现代替代方案
C++11后，优先使用constexpr函数替代模板元编程：
1. 代码更清晰、更易调试
2. 编译速度更快
3. 错误信息更友好
4. 可以同时在编译期和运行期使用 
// 现代方式：使用constexpr
constexpr int factorial(int n) {
    return n <= 1 ? 1 : n * factorial(n - 1);
}

constexpr int result = factorial(5);  // 编译期计算

🎭 4.2 SFINAE技术

基本原理

SFINAE (Substitution Failure Is Not An Error)：替换失败不是错误。当模板参数替换失败时，编译器不会报错，而是从候选集中移除该模板。

🔄 SFINAE工作流程
1. 编译器收集所有可能的函数候选
2. 尝试模板参数替换
3. 替换失败？从候选集移除（不报错）
4. 替换成功？加入有效候选
5. 选择最佳匹配

使用enable_if进行SFINAE

// 返回类型SFINAE
template<typename T>
typename std::enable_if<std::is_integral<T>::value, T>::type
process(T value) {
    return value * 2;  // 仅对整型有效
}

template<typename T>
typename std::enable_if<std::is_floating_point<T>::value, T>::type
process(T value) {
    return value / 2.0;  // 仅对浮点型有效
}

// 参数SFINAE (C++14后更简洁)
template<typename T, 
         typename = std::enable_if_t<std::is_integral_v<T>>>
auto process_v2(T value) {
    return value * 2;
}

// 非类型模板参数SFINAE
template<typename T, 
         std::enable_if_t<std::is_integral_v<T>, int> = 0>
void foo(T value) {
    std::cout << "Integral: " << value << "\n";
}

检测成员函数是否存在

// 传统方法：使用decltype + 逾号表达式
template<typename T>
class has_size_method {
    template<typename U>
    static auto test(int) -> decltype(
        std::declval<U>().size(), std::true_type{}
    );
    
    template<typename>
    static std::false_type test(...);
    
public:
    static constexpr bool value = decltype(test<T>(0))::value;
};

// C++17: 使用void_t
template<typename, typename = void>
struct has_size : std::false_type {};

template<typename T>
struct has_size<T, std::void_t<decltype(std::declval<T>().size())>>
    : std::true_type {};

// 使用
static_assert(has_size<std::vector<int>>::value);  // true
static_assert(!has_size<int>::value);           // true

// 检测多个成员
template<typename, typename = void>
struct is_container : std::false_type {};

template<typename T>
struct is_container<T, std::void_t<
    typename T::value_type,
    typename T::iterator,
    decltype(std::declval<T>().begin()),
    decltype(std::declval<T>().end())
>> : std::true_type {};

void_t技巧详解

// void_t的实现
template<typename...>
using void_t = void;

// 工作原理：
// 1. 如果模板参数中的表达式都有效，void_t结果为void
// 2. 如果任何表达式无效，SFINAE使特化失败
// 3. 失败后使用主模板 (false_type)

// 应用：检测操作符
template<typename, typename = void>
struct has_plus : std::false_type {};

template<typename T>
struct has_plus<T, std::void_t<
    decltype(std::declval<T>() + std::declval<T>())
>> : std::true_type {};

Detection Idiom (C++17实验性特性)

// 通用的检测器
template<typename Default, typename AlwaysVoid,
         template<typename...> class Op, typename... Args>
struct detector {
    using value_t = std::false_type;
    using type = Default;
};

template<typename Default, template<typename...> class Op, typename... Args>
struct detector<Default, std::void_t<Op<Args...>>, Op, Args...> {
    using value_t = std::true_type;
    using type = Op<Args...>;
};

// 定义检测操作
template<typename T>
using size_type_t = typename T::size_type;

template<typename T>
using has_size_type = typename detector<void, void, size_type_t, T>::value_t;

📦 4.3 变参模板

C++11引入的强大特性，支持任意数量的模板参数。

参数包基础

// 参数包声明
template<typename... Args>  // Args是类型参数包
void func(Args... args);        // args是函数参数包

// 获取参数包大小
template<typename... Args>
constexpr size_t count() {
    return sizeof...(Args);  // 类型数量
}

template<typename... Args>
void count_args(Args... args) {
    std::cout << sizeof...(args) << " arguments\\n";  // 参数数量
}

递归展开

// 传统递归展开
void print() {  // 终止函数
    std::cout << "\\n";
}

template<typename T, typename... Args>
void print(T first, Args... rest) {
    std::cout << first << " ";
    print(rest...);  // 递归调用
}

print(1, 2.5, "hello", 'a');  // 输出：1 2.5 hello a

// C++17: if constexpr替代终止函数
template<typename T, typename... Args>
void print_v2(T first, Args... rest) {
    std::cout << first;
    if constexpr (sizeof...(rest) > 0) {
        std::cout << " ";
        print_v2(rest...);
    } else {
        std::cout << "\\n";
    }
}

C++17折叠表达式

折叠表达式是C++17的杀手级特性，使变参模板代码极度简洁。

折叠类型语法展开结果
一元右折叠 (args + ...) a1 + (a2 + (a3 + a4))
一元左折叠 (... + args) ((a1 + a2) + a3) + a4
二元右折叠 (args + ... + init) a1 + (a2 + (a3 + (a4 + init)))
二元左折叠 (init + ... + args) ((((init + a1) + a2) + a3) + a4) 
// 一元右折叠：求和
template<typename... Args>
auto sum(Args... args) {
    return (args + ...);  // a1 + a2 + a3 + ...
}

// 一元左折叠：打印
template<typename... Args>
void print_fold(Args... args) {
    (std::cout << ... << args) << "\\n";  // cout << a1 << a2 << ...
}

// 逻辑操作：全部为true
template<typename... Args>
bool all(Args... args) {
    return (args && ...);  // a1 && a2 && a3 && ...
}

// 函数调用展开
template<typename... Args>
void call_all(Args... funcs) {
    (funcs(), ...);  // 调用所有函数
}

索引序列技巧

// 使用索引序列展开元组
template<typename Tuple, size_t... Is>
void print_tuple_impl(Tuple&& t, std::index_sequence<Is...>) {
    ((std::cout << std::get<Is>(t) << " "), ...);
    std::cout << "\\n";
}

template<typename... Args>
void print_tuple(const std::tuple<Args...>& t) {
    print_tuple_impl(t, std::index_sequence_for<Args...>{});
}

// 使用
auto t = std::make_tuple(1, 2.5, "hello");
print_tuple(t);  // 输出：1 2.5 hello

// 应用：apply函数（将元组展开为函数参数）
template<typename Func, typename Tuple, size_t... Is>
auto apply_impl(Func&& f, Tuple&& t, std::index_sequence<Is...>) {
    return f(std::get<Is>(std::forward<Tuple>(t))...);
}

template<typename Func, typename Tuple>
auto apply(Func&& f, Tuple&& t) {
    constexpr auto size = std::tuple_size_v<std::decay_t<Tuple>>;
    return apply_impl(std::forward<Func>(f), 
                       std::forward<Tuple>(t),
                       std::make_index_sequence<size>{});
}

✨ 4.4 C++20 Concepts

定义Concept

// 定义数值概念
template<typename T>
concept Numeric = std::is_arithmetic_v<T>;

// 定义容器概念
template<typename T>
concept Container = requires(T c) {
    { c.begin() } -> std::same_as<typename T::iterator>;
    { c.end() } -> std::same_as<typename T::iterator>;
    { c.size() } -> std::convertible_to<size_t>;
};

使用Concept约束模板

// 方式1：requires子句
template<typename T>
    requires Numeric<T>
T add(T a, T b) {
    return a + b;
}

// 方式2：简化语法
template<Numeric T>
T multiply(T a, T b) {
    return a * b;
}

// 方式3：简写函数模板
auto divide(Numeric auto a, Numeric auto b) {
    return a / b;
}

🚀 4.6 编译期优化技巧

if constexpr - 编译期分支裁剪

// 传统方式：使用SFINAE（两个函数）
template<typename T>
std::enable_if_t<std::is_integral_v<T>>
process_old(T value) {
    return value * 2;
}

template<typename T>
std::enable_if_t<std::is_floating_point_v<T>>
process_old(T value) {
    return value / 2.0;
}

// C++17: 使用if constexpr（一个函数）
template<typename T>
auto process_new(T value) {
    if constexpr (std::is_integral_v<T>) {
        return value * 2;  // 浮点型时此分支被裁剪
    } else {
        return value / 2.0;  // 整型时此分支被裁剪
    }
}

constexpr函数 - 替代模板元编程

// 老式模板元编程：复杂且难调试
template<int N>
struct Factorial {
    static constexpr int value = N * Factorial<N-1>::value;
};
template<> struct Factorial<0> { static constexpr int value = 1; };

// 现代方式：constexpr函数
constexpr int factorial(int n) {
    return n <= 1 ? 1 : n * factorial(n - 1);
}

// constexpr还能在运行期使用
int n;
std::cin >> n;
int result = factorial(n);  // 运行期计算

代码去重 - 提取公共基类

// 问题：模板代码膨胀
template<typename T>
class Vector {
    T* data;
    size_t size;
    
    void resize(size_t new_size) { /* 大量与类型无关的代码 */ }
    void check_bounds(size_t index) { /* 与类型无关 */ }
};

// 解决：提取到非模板基类
class VectorBase {  // 非模板基类
protected:
    void* data;
    size_t size;
    size_t capacity;
    
    void resize_impl(size_t new_size, size_t elem_size);
    void check_bounds(size_t index);
};

template<typename T>
class Vector : private VectorBase {
public:
    void resize(size_t n) { resize_impl(n, sizeof(T)); }
    T& operator[](size_t i) { 
        check_bounds(i); 
        return static_cast<T*>(data)[i]; 
    }
};

extern template - 减少编译时间

// vector.h
template<typename T>
class Vector {
    // ...
};

// vector.cpp - 显式实例化
template class Vector<int>;     // 强制实例化
template class Vector<double>;

// main.cpp - 禁止隐式实例化
extern template class Vector<int>;     // 告诉编译器不要在此实例化
extern template class Vector<double>;

Vector<int> v;  // 使用vector.cpp中的实例，减少编译时间
