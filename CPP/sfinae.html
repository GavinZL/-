    📖 知识体系总览

    SFINAE（Substitution Failure Is Not An Error）是C++模板元编程中最重要的特性之一。它允许编译器在模板参数替换失败时，不将其视为错误，而是从候选函数集中移除该模板。

    🎯 第一层：概念与背景

    1.1 SFINAE的诞生背景

    // 如果没有SFINAE，这段代码会编译失败
template<typename T>
void process(T value, typename T::value_type* = nullptr) {
    // 处理有value_type的类型
}

template<typename T>
void process(T value, ...) {
    // 处理其他类型
}

process(42);  // int没有value_type，SFINAE选择第二个版本
    📌 核心原则 当模板参数替换导致无效类型或表达式时，编译器不报错，而是将该模板从候选集中移除。

    1.2 SFINAE vs 编译错误

    类型 发生位置 结果
    软错误 函数签名（返回类型、参数类型） 触发SFINAE，选择其他重载
    硬错误 函数体内、类定义内 编译失败

    ⚙️ 第二层：核心机制与实现原理

    2.1 SFINAE友好的上下文

    上下文 SFINAE友好 示例
    函数返回类型 ✅ typename T::type func()
    函数参数类型 ✅ void func(typename T::type)
    模板参数 ✅ template<typename = typename T::type>
    decltype表达式 ✅ decltype(t.func())
    函数体内 ❌ { typename T::type x; }

    2.2 常见SFINAE模式

    // 模式1：返回类型SFINAE
template<typename T>
typename T::value_type get_value(T t);

// 模式2：额外模板参数SFINAE
template<typename T, typename = typename T::iterator>
void process(T t);

// 模式3：decltype SFINAE
template<typename T>
auto call_begin(T& t) -> decltype(t.begin());

    3.1 enable_if实现原理

struct enable_if {};

// 使用

         typename = std::enable_if_t<std::is_integral_v<T>>>

    3.2 检测成员函数存在性

    // C++17 void_t方法
template<typename T, typename = void>
struct has_begin : std::false_type {};

template<typename T>
struct has_begin<T, std::void_t<decltype(std::declval<T>().begin())>>
    : std::true_type {};

static_assert(has_begin<std::vector<int>>::value);

    🚀 第四层：高级技巧与最佳实践

    4.1 void_t技巧

    // void_t定义
template<typename... Ts>
using void_t = void;

// 应用：检测任意表达式
template<typename T, typename = void>
struct is_printable : std::false_type {};

template<typename T>
struct is_printable<T, std::void_t<
    decltype(std::cout << std::declval<T>())
>> : std::true_type {};

    4.2 现代C++替代方案

    // C++17: if constexpr
template<typename T>
auto process(T value) {
    if constexpr (std::is_integral_v<T>) {
        return value * 2;
    } else {
        return value;
    }
}

// C++20: Concepts
template<typename T>
concept Integral = std::is_integral_v<T>;

template<Integral T>
void process(T value) {}
