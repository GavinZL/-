📜 1.1 模板的起源与演进

C++模板诞生背景 (1990年代初期)

方面详细说明
历史契机1988年，Bjarne Stroustrup和Andrew Koenig提出模板概念
设计目标实现类型安全的泛型编程，避免宏的缺陷
核心理念编译期多态，零运行时开销抽象
首次应用STL由Alexander Stepanov设计，成为模板技术的杀手级应用

C++98/03 标准时期

模板技术的奠基阶段，确立了基础语法和核心概念。

// C++98 基础函数模板
template<typename T>
void swap(T& a, T& b) {
    T temp = a;
    a = b;
    b = temp;
}

// C++98 基础类模板
template<typename T>
class Vector {
    T* data;
    size_t size;
public:
    Vector(size_t n) : data(new T[n]), size(n) {}
    T& operator[](size_t i) { return data[i]; }
};

C++11 革命性变革

引入变参模板、右值引用、完美转发等现代化特性。

// C++11 变参模板 + 完美转发
template<typename T, typename... Args>
std::unique_ptr<T> make_unique(Args&&... args) {
    return std::unique_ptr<T>(new T(std::forward<Args>(args)...));
}

// C++11 移动语义
template<typename T>
class Container {
    T* data;
public:
    Container(Container&& other) noexcept 
        : data(other.data) {
        other.data = nullptr;
    }
};

C++17 实用性增强

// 类模板参数推导 (CTAD)
std::pair p{1, 2.5};  // pair<int, double>
std::vector v{1, 2, 3}; // vector<int>

// 折叠表达式
template<typename... Args>
auto sum(Args... args) {
    return (args + ...);
}

// if constexpr 编译期分支
template<typename T>
auto process(T value) {
    if constexpr (std::is_integral_v<T>) {
        return value * 2;
    } else {
        return value;
    }
}

C++20 范式转变 - Concepts

// C++20 Concepts
template<typename T>
concept Numeric = std::is_arithmetic_v<T>;

template<Numeric T>
T add(T a, T b) { return a + b; }

// 简写函数模板
auto multiply(Numeric auto a, Numeric auto b) {
    return a * b;
}

// Ranges组合式算法
auto result = nums 
    | std::views::filter([](auto x) { return x % 2 == 0; })
    | std::views::transform([](auto x) { return x * x; });

🔍 1.2 模板的本质与价值

模板 vs 宏 vs 继承多态

特性模板宏继承多态
类型安全✅ 强类型检查❌ 无类型检查✅ 类型安全
绑定时机编译期预处理运行期
性能✅ 零运行时开销✅ 零开销⚠️ 虚函数开销
代码膨胀⚠️ 每类型一份⚠️ 宏展开✅ 一份代码
调试性✅ 可调试❌ 难调试✅ 易调试
 
// 1. 宏的方式（不推荐）
#define MAX(a, b) ((a) > (b) ? (a) : (b))
// 问题：无类型检查，可能多次计算参数

// 2. 模板的方式（推荐）
template<typename T>
const T& max(const T& a, const T& b) {
    return (a > b) ? a : b;
}

// 3. 继承多态的方式
class Base {
public:
    virtual void process() = 0;
};

🎯 1.3 泛型编程范式

STL的设计哲学

STL三大组件
📦 容器：vector, list, map, set
🔄 迭代器：输入、输出、前向、双向、随机访问
⚙️ 算法：sort, find, transform, accumulate
// STL泛型编程：算法与容器分离
std::vector<int> vec = {5, 2, 8, 1};
std::list<int> lst = {5, 2, 8, 1};

// 同一算法作用于不同容器
std::sort(vec.begin(), vec.end());
auto it1 = std::find(vec.begin(), vec.end(), 8);
auto it2 = std::find(lst.begin(), lst.end(), 8);
💡 泛型编程核心原则 1. 最小假设原则：算法只假设类型具有必要的操作
2. 最大通用性：算法应能适用于尽可能多的类型
3. 零开销抽象：抽象不应带来运行时性能损失
4. 组合性：组件可以自由组合使用

📊 1.4 C++类型系统基础

类型分类体系

类型类别具体类型说明
基本类型int, float, double, char, bool内置的基础类型
复合类型指针、引用、数组、函数由基本类型构建
用户定义class, struct, enum, union程序员自定义

值类别 (Value Category) - C++11后

值类别定义典型例子
lvalue有名字的对象变量名、*ptr、返回T&的函数
prvalue纯右值，临时对象字面量42、返回T的函数
xvalue将亡值std::move(x)、返回T&&的函数
glvalue广义左值 = lvalue + xvalue有内存位置的表达式
rvalue右值 = prvalue + xvalue可以出现在赋值右侧

类型推导规则

推导方式规则示例
auto类似模板参数推导auto x = 42;
decltype保持表达式类型decltype(expr)
模板T标准推导规则template<typename T>
 
// 类型推导示例
int x = 10;
auto a = x;           // a是int
auto& b = x;          // b是int&
decltype(x) c = x;   // c是int
decltype((x)) d = x; // d是int&（表达式是lvalue）

// 引用折叠规则
template<typename T>
void func(T&& param);  // 万能引用
// T& + & = T&
// T& + && = T&
// T&& + & = T&
// T&& + && = T&&
