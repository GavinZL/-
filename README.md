# 50道常见面试算法题集合

## 项目简介

本项目是一个系统化、结构化的算法面试题集合，以单个HTML页面形式呈现，包含50道精选高频算法面试题。

## 特点

✨ **离线可用** - 单个HTML文件，无需网络连接
📚 **支持打印** - 优化的打印样式，方便学习复习
🔗 **便捷导航** - 快速锚点跳转，分类清晰
🎨 **美观界面** - 现代化设计，阅读体验良好
📊 **深度解析** - 包含算法思路、复杂度分析、流程图

## 内容结构

### 数据结构分类（39题）
- **数组（6题）**：两数之和、三数之和、合并有序数组、搜索二维矩阵、螺旋矩阵、接雨水
- **链表（8题）**：反转链表、环形链表、合并有序链表、相交链表、K个一组翻转链表等
- **二叉树（9题）**：前中序遍历、层序遍历、最大深度、验证BST、最近公共祖先等
- **栈与队列（4题）**：有效的括号、最小栈、用栈实现队列、滑动窗口最大值
- **哈希表（4题）**：LRU缓存、最长连续序列、多数元素、缺失的第一个正数
- **字符串（5题）**：无重复字符的最长子串、最长回文子串、字符串相加等
- **堆（2题）**：第K个最大元素、合并K个排序链表

### 算法思想分类（13题）
- **动态规划（11题）**：爬楼梯、买卖股票、最大子数组和、零钱兑换、编辑距离等
- **回溯法（2题）**：全排列、子集

### 其他算法（引用形式）
- 双指针、滑动窗口、二分查找等相关题目已包含在数据结构分类中

## 使用方法

### 在线浏览
1. 直接用浏览器打开 `50-algorithm-interview-questions.html`
2. 无需任何服务器或网络连接

### 打印或保存PDF
1. 在浏览器中打开文件
2. 使用浏览器的打印功能（Ctrl+P 或 Cmd+P）
3. 选择"另存为PDF"或直接打印

### 导航使用
- 点击顶部导航栏快速跳转到对应分类
- 点击题目标题展开/收起详细内容
- 点击相关题目链接跳转到对应题目

## 学习路径建议

### 零基础学习者（6-7周）
**第一阶段：数据结构基础（2周）**
- 数组 → 链表 → 栈与队列 → 哈希表
- 每天2-3题，侧重简单题

**第二阶段：树与算法基础（2周）**
- 二叉树遍历 → 基础算法
- 每天2题，简单+中等

**第三阶段：进阶算法（3周）**
- 回溯 → 动态规划
- 每天1-2题，侧重中等题

### 有基础准备面试者（1周）
- 快速复习模式，按分类每天一个主题
- 重点关注中等和困难题
- 总结解题模板和套路
