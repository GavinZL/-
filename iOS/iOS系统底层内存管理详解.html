三、libmalloc核心机制

3.1 Zone分配器选择

void *malloc(size_t size) {
    if (size <= 256)   return nano_malloc(size);
    if (size <= 1008)  return tiny_malloc(size);
    if (size <= 15360) return small_malloc(size);
    if (size <= 131072)return medium_malloc(size);
    return large_malloc(size);
}

五、Magazine多核优化

5.1 Magazine结构

typedef struct {
    void *mag_last_free;         // LIFO缓存
    msize_t mag_last_free_msize;
    free_list_t free_list[64];  // 64个free list

5.2 Per-Thread Magazine

每个线程独立Magazine，减少锁竞争：

优化原理：
  • 每线程独立内存池
  • 无锁快速路径 (mag_last_free)
  • 降低缓存行竞争
  • 多核扩展性提升10x+

8.2 kalloc_type (类型隔离)

Type Isolation原理：
  • 每种类型独立zone
  • 防止类型混淆攻击
  • UAF无法替换为其他类型
  • iOS 14+默认启用
