## 1. 数据同步概述

### 1.1 为什么数据同步是性能关键

在移动端渲染中，CPU和GPU是异步工作的独立处理单元。数据同步机制决定了：

- **延迟控制**：数据何时可被GPU使用
- **带宽利用**：如何高效传输大量数据
- **并行效率**：CPU/GPU能否真正并行工作
- **功耗影响**：不当的同步会增加等待功耗

**数据流向分析**

```
渲染数据流：

CPU → GPU（上传）
├── 顶点数据（VBO）
├── 索引数据（IBO）
├── 纹理数据（Texture）
├── Uniform数据（UBO）
└── 计算数据（SSBO）

GPU → CPU（回读）
├── 像素数据（glReadPixels/PBO）
├── 查询结果（Query）
├── Transform Feedback结果
└── 计算着色器输出
```

### 1.2 同步机制分类

| 机制类型 | OpenGL ES版本 | 主要用途 | 性能特点 |
|---------|--------------|---------|---------|
| VBO/IBO | ES 2.0+ | 顶点/索引 | 基础同步 |
| UBO | ES 3.0+ | Uniform块 | 批量Uniform |
| PBO | ES 3.0+ | 像素传输 | 异步传输 |
| SSBO | ES 3.1+ | 通用缓冲 | 可读写 |
| Fence Sync | ES 3.0+ | 同步控制 | 细粒度 |
| Query | ES 3.0+ | 异步查询 | 状态查询 |
| HardwareBuffer | Android 8+ | 零拷贝 | 最高效率 |
| CVPixelBuffer | iOS | 零拷贝 | 最高效率 |

### 2.1 缓冲使用模式

**Usage Hints的正确使用**

```cpp
// 缓冲使用模式选择指南
enum BufferUsageGuide {
    // STATIC: 数据一次设置，多次使用
    // 适用：静态网格、地形、预计算数据

    GL_DYNAMIC_DRAW,

    // 适用：视频帧、实时生成几何体
    GL_STREAM_DRAW,

class BufferManager {
public:
    GLuint CreateBuffer(BufferType type, size_t size, const void* data) {
        GLuint buffer;
        glGenBuffers(1, &buffer);
        glBindBuffer(GL_ARRAY_BUFFER, buffer);
        
        GLenum usage;
        switch (type) {
            case BufferType::StaticMesh:
                usage = GL_STATIC_DRAW;
                break;
            case BufferType::AnimatedMesh:
                usage = GL_DYNAMIC_DRAW;
                break;
            case BufferType::ParticleSystem:
                usage = GL_STREAM_DRAW;
                break;
            default:
                usage = GL_STATIC_DRAW;
        }
        
        glBufferData(GL_ARRAY_BUFFER, size, data, usage);
        return buffer;
    }
};
```

### 2.2 Buffer Orphaning技术

当需要更新正在被GPU使用的缓冲时，直接修改会导致CPU等待。Buffer Orphaning让驱动分配新内存，避免同步。

**实现代码**

```cpp
// Buffer Orphaning实现
class OrphanedBuffer {
public:
    void Initialize(size_t size) {
        glGenBuffers(1, &buffer);
        glBindBuffer(GL_ARRAY_BUFFER, buffer);
        glBufferData(GL_ARRAY_BUFFER, size, nullptr, GL_STREAM_DRAW);
        this->size = size;
    }
    
    // 方法1：重新分配（隐式Orphaning）
    void UpdateWithOrphan(const void* data, size_t dataSize) {
        glBindBuffer(GL_ARRAY_BUFFER, buffer);
        
        // 传入nullptr大小相同的调用会让驱动分配新内存
        // 旧内存等GPU用完后自动释放
        glBufferData(GL_ARRAY_BUFFER, size, nullptr, GL_STREAM_DRAW);
        glBufferSubData(GL_ARRAY_BUFFER, 0, dataSize, data);
    }
    
    // 方法2：使用glMapBufferRange with INVALIDATE
    void UpdateWithMap(const void* data, size_t dataSize) {
        glBindBuffer(GL_ARRAY_BUFFER, buffer);
        
        void* mapped = glMapBufferRange(
            GL_ARRAY_BUFFER,
            0, size,
            GL_MAP_WRITE_BIT | 
            GL_MAP_INVALIDATE_BUFFER_BIT  // 关键：告知驱动丢弃旧数据
        );
        
        if (mapped) {
            memcpy(mapped, data, dataSize);
            glUnmapBuffer(GL_ARRAY_BUFFER);
        }
    }
    
private:
    GLuint buffer;
    size_t size;
};

// 性能对比测试
class OrphanBenchmark {
```

### 2.3 多缓冲（Ring Buffer）

使用多个缓冲轮换，确保CPU更新的缓冲不在GPU使用中。

```cpp
// 环形缓冲实现
template<int BUFFER_COUNT = 3>
class RingBuffer {
public:
    void Initialize(size_t bufferSize) {
        glGenBuffers(BUFFER_COUNT, buffers);
        
        for (int i = 0; i < BUFFER_COUNT; ++i) {
            glBindBuffer(GL_ARRAY_BUFFER, buffers[i]);
            glBufferData(GL_ARRAY_BUFFER, bufferSize, nullptr, GL_DYNAMIC_DRAW);
        }
        
        this->bufferSize = bufferSize;
    }
    
    // 获取当前可写入的缓冲
    GLuint GetCurrentBuffer() {
        return buffers[currentIndex];
    }
    
    // 更新数据并切换到下一个缓冲
    void UpdateAndAdvance(const void* data, size_t size) {
        GLuint buffer = buffers[currentIndex];
        
        glBindBuffer(GL_ARRAY_BUFFER, buffer);
        glBufferSubData(GL_ARRAY_BUFFER, 0, size, data);
        
        // 移动到下一个缓冲
        currentIndex = (currentIndex + 1) % BUFFER_COUNT;
    }
    
    // 带Fence的高级版本
    void UpdateWithFence(const void* data, size_t size) {
        // 等待该缓冲的前一次使用完成
        if (fences[currentIndex]) {
            GLenum result = glClientWaitSync(
                fences[currentIndex], 
                GL_SYNC_FLUSH_COMMANDS_BIT,
                1000000000  // 1秒超时
            );
            
            if (result == GL_TIMEOUT_EXPIRED) {
                LOG("Warning: Fence timeout, potential stall");
            }
            
            glDeleteSync(fences[currentIndex]);
            fences[currentIndex] = nullptr;
        }
        
        // 更新数据
        GLuint buffer = buffers[currentIndex];
        glBindBuffer(GL_ARRAY_BUFFER, buffer);
        glBufferSubData(GL_ARRAY_BUFFER, 0, size, data);
        
        currentIndex = (currentIndex + 1) % BUFFER_COUNT;
    }
    
    // 在绘制后插入Fence
    void InsertFenceAfterDraw() {
        int prevIndex = (currentIndex + BUFFER_COUNT - 1) % BUFFER_COUNT;
        fences[prevIndex] = glFenceSync(GL_SYNC_GPU_COMMANDS_COMPLETE, 0);
    }
    
private:
    GLuint buffers[BUFFER_COUNT];
    GLsync fences[BUFFER_COUNT] = {nullptr};
    int currentIndex = 0;
    size_t bufferSize;
};

// 使用示例：粒子系统
class ParticleRenderer {
public:
    void Initialize(int maxParticles) {
        particleBuffer.Initialize(maxParticles * sizeof(Particle));
    }
    
    void UpdateAndRender(const std::vector<Particle>& particles) {
        // 更新当前缓冲
        particleBuffer.UpdateAndAdvance(
            particles.data(), 
            particles.size() * sizeof(Particle)
        );
        
        // 设置顶点属性
        glBindBuffer(GL_ARRAY_BUFFER, particleBuffer.GetCurrentBuffer());
        SetupVertexAttributes();
        
        // 绘制
        glDrawArrays(GL_POINTS, 0, particles.size());
        
        // 可选：插入Fence用于下一帧同步
        // particleBuffer.InsertFenceAfterDraw();
    }
    
private:
    RingBuffer<3> particleBuffer;
};
```

**多缓冲性能收益**

## 3. PBO异步传输

### 3.1 PBO原理

PBO（Pixel Buffer Object）允许异步进行像素数据传输，CPU可在传输过程中继续工作。

```
传统方式（同步）：
CPU准备数据 ──等待──> GPU传输 ──等待──> CPU继续
                 ↑          ↑
               阻塞        阻塞

PBO方式（异步）：
CPU准备数据 ──> PBO缓冲 ──DMA传输──> GPU纹理
     │                      │
     └──(CPU继续工作)        └──(并行)
```

### 3.2 纹理异步上传

```cpp
// PBO异步纹理上传
class AsyncTextureUploader {
public:
    static const int PBO_COUNT = 2;  // 双缓冲PBO
    
    void Initialize(int width, int height) {
        this->width = width;
        this->height = height;
        size_t bufferSize = width * height * 4;  // RGBA
        
        // 创建PBO
        glGenBuffers(PBO_COUNT, pbos);
        for (int i = 0; i < PBO_COUNT; ++i) {
            glBindBuffer(GL_PIXEL_UNPACK_BUFFER, pbos[i]);
            glBufferData(GL_PIXEL_UNPACK_BUFFER, bufferSize, 
                         nullptr, GL_STREAM_DRAW);
        }
        
        // 创建目标纹理
        glGenTextures(1, &texture);
        glBindTexture(GL_TEXTURE_2D, texture);
        glTexImage2D(GL_TEXTURE_2D, 0, GL_RGBA8, width, height, 0,
                     GL_RGBA, GL_UNSIGNED_BYTE, nullptr);
        glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MIN_FILTER, GL_LINEAR);
        glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MAG_FILTER, GL_LINEAR);
    }
    
    // 异步上传（双缓冲流水线）
    void UploadAsync(const void* pixelData) {
        int currentPBO = frameIndex % PBO_COUNT;
        int nextPBO = (frameIndex + 1) % PBO_COUNT;
        
        // 步骤1：将新数据上传到当前PBO
        glBindBuffer(GL_PIXEL_UNPACK_BUFFER, pbos[currentPBO]);
        
        // 使用glMapBufferRange避免同步
        void* mapped = glMapBufferRange(
            GL_PIXEL_UNPACK_BUFFER,
            0, width * height * 4,
            GL_MAP_WRITE_BIT | GL_MAP_INVALIDATE_BUFFER_BIT
        );
        
        if (mapped) {
            memcpy(mapped, pixelData, width * height * 4);
            glUnmapBuffer(GL_PIXEL_UNPACK_BUFFER);
        }
        
        // 步骤2：使用上一帧的PBO更新纹理（数据已就绪）
        if (frameIndex > 0) {
            glBindBuffer(GL_PIXEL_UNPACK_BUFFER, pbos[nextPBO]);
            glBindTexture(GL_TEXTURE_2D, texture);
            
            // nullptr表示从绑定的PBO读取
            glTexSubImage2D(GL_TEXTURE_2D, 0, 0, 0, width, height,
                            GL_RGBA, GL_UNSIGNED_BYTE, nullptr);
        }
        
        glBindBuffer(GL_PIXEL_UNPACK_BUFFER, 0);
        frameIndex++;
    }
    
    GLuint GetTexture() const { return texture; }
    
private:
    GLuint pbos[PBO_COUNT];
    GLuint texture;
    int width, height;
    int frameIndex = 0;
};

// 使用示例：视频帧上传
class VideoRenderer {
public:
    void Initialize(int videoWidth, int videoHeight) {
        uploader.Initialize(videoWidth, videoHeight);
    }
    
    void OnVideoFrame(const VideoFrame& frame) {
        // 异步上传，不阻塞解码线程
        uploader.UploadAsync(frame.pixels);
    }
    
    void Render() {
        glBindTexture(GL_TEXTURE_2D, uploader.GetTexture());
        DrawFullscreenQuad();
    }
    
private:
    AsyncTextureUploader uploader;
};
```

### 3.3 异步像素回读

```cpp
// PBO异步像素回读
class AsyncPixelReader {
public:
    static const int PBO_COUNT = 2;
    
    void Initialize(int width, int height) {
        this->width = width;
        this->height = height;
        size_t bufferSize = width * height * 4;
        
        glGenBuffers(PBO_COUNT, pbos);
        for (int i = 0; i < PBO_COUNT; ++i) {
            glBindBuffer(GL_PIXEL_PACK_BUFFER, pbos[i]);
            glBufferData(GL_PIXEL_PACK_BUFFER, bufferSize,
                         nullptr, GL_STREAM_READ);
        }
    }
    
    // 发起异步读取
    void BeginRead() {
        int currentPBO = frameIndex % PBO_COUNT;
        
        glBindBuffer(GL_PIXEL_PACK_BUFFER, pbos[currentPBO]);
        
        // nullptr表示写入绑定的PBO，不阻塞
        glReadPixels(0, 0, width, height,
                     GL_RGBA, GL_UNSIGNED_BYTE, nullptr);
        
        glBindBuffer(GL_PIXEL_PACK_BUFFER, 0);
    }
    
    // 获取上一帧的读取结果
    const void* GetReadResult() {
        if (frameIndex < 1) return nullptr;
        
        int prevPBO = (frameIndex + PBO_COUNT - 1) % PBO_COUNT;
        
        glBindBuffer(GL_PIXEL_PACK_BUFFER, pbos[prevPBO]);
        
        // 映射读取（此时数据应已准备好）
        const void* data = glMapBufferRange(
            GL_PIXEL_PACK_BUFFER,
            0, width * height * 4,
            GL_MAP_READ_BIT
        );
        
        return data;
    }
    
    void EndRead() {
        glUnmapBuffer(GL_PIXEL_PACK_BUFFER);
        glBindBuffer(GL_PIXEL_PACK_BUFFER, 0);
        frameIndex++;
    }
    
private:
    GLuint pbos[PBO_COUNT];
    int width, height;
    int frameIndex = 0;
};

// 使用示例：截图功能
class ScreenCapture {
public:
    void Initialize(int screenWidth, int screenHeight) {
        reader.Initialize(screenWidth, screenHeight);
        pixelBuffer.resize(screenWidth * screenHeight * 4);
        this->width = screenWidth;
        this->height = screenHeight;
    }
    
    // 每帧调用（流水线）
    void CaptureFrame() {
        // 获取上一帧结果
        const void* prevData = reader.GetReadResult();
        if (prevData) {
            memcpy(pixelBuffer.data(), prevData, pixelBuffer.size());
            reader.EndRead();
            
            // 处理截图（如保存到文件）
            ProcessCapture(pixelBuffer.data(), width, height);
        }
        
        // 发起新的读取
        reader.BeginRead();
    }
    
private:
    AsyncPixelReader reader;
    std::vector<uint8_t> pixelBuffer;
    int width, height;
};
```

## 4. Fence同步与Query

### 4.1 Fence Sync基础

Fence是GPU命令流中的同步点，用于精确控制CPU/GPU同步。

```cpp
// Fence Sync管理器
class FenceSyncManager {
public:
    // 插入Fence（在GPU命令流中）
    GLsync InsertFence() {
        return glFenceSync(GL_SYNC_GPU_COMMANDS_COMPLETE, 0);
    }
    
    // 检查Fence状态（非阻塞）
    bool IsFenceComplete(GLsync fence) {
        GLint status;
        glGetSynciv(fence, GL_SYNC_STATUS, 1, nullptr, &status);
        return status == GL_SIGNALED;
    }
    
    // 等待Fence（阻塞）
    WaitResult WaitForFence(GLsync fence, uint64_t timeoutNs = 0) {
        GLenum result = glClientWaitSync(
            fence,
            GL_SYNC_FLUSH_COMMANDS_BIT,
            timeoutNs
        );
        
        switch (result) {
            case GL_ALREADY_SIGNALED:
                return WaitResult::AlreadyComplete;
            case GL_CONDITION_SATISFIED:
                return WaitResult::Completed;
            case GL_TIMEOUT_EXPIRED:
                return WaitResult::Timeout;
            case GL_WAIT_FAILED:
                return WaitResult::Failed;
            default:
                return WaitResult::Unknown;
        }
    }
    
    // 非阻塞等待（CPU不阻塞，GPU等待）
    void WaitOnGPU(GLsync fence) {
        glWaitSync(fence, 0, GL_TIMEOUT_IGNORED);
    }
    
    // 删除Fence
    void DeleteFence(GLsync fence) {
        if (fence) {
            glDeleteSync(fence);
        }
    }
    
    enum class WaitResult {
        AlreadyComplete,
        Completed,
        Timeout,
        Failed,
        Unknown
    };
};

// 高级用法：帧同步管理
class FrameSyncManager {
public:
    static const int FRAME_LAG = 2;  // 允许GPU落后2帧
    
    void Initialize() {
        for (int i = 0; i < FRAME_LAG; ++i) {
            frameFences[i] = nullptr;
        }
    }
    
    // 在每帧开始时调用
    void BeginFrame() {
        int fenceIndex = frameCount % FRAME_LAG;
        
        // 等待旧的帧完成
        if (frameFences[fenceIndex]) {
            auto result = syncManager.WaitForFence(
                frameFences[fenceIndex],
                16000000  // 16ms超时
            );
            
            if (result == FenceSyncManager::WaitResult::Timeout) {
                LOG("Frame sync timeout - GPU falling behind");
            }
            
            syncManager.DeleteFence(frameFences[fenceIndex]);
        }
    }
    
    // 在每帧结束时调用
    void EndFrame() {
        int fenceIndex = frameCount % FRAME_LAG;
        frameFences[fenceIndex] = syncManager.InsertFence();
        frameCount++;
    }
    
private:
    FenceSyncManager syncManager;
    GLsync frameFences[FRAME_LAG];
    uint64_t frameCount = 0;
};
```

### 4.2 Query对象

Query用于异步获取GPU状态信息。

```cpp
// GPU时间查询
class GPUTimeQuery {
public:
    void Initialize() {
        if (!CheckExtension("GL_EXT_disjoint_timer_query")) {
            LOG("Timer query not supported");
            return;
        }
        
        glGenQueries = (PFNGLGENQUERIESEXTPROC)
            eglGetProcAddress("glGenQueriesEXT");
        glDeleteQueries = (PFNGLDELETEQUERIESEXTPROC)
            eglGetProcAddress("glDeleteQueriesEXT");
        glBeginQuery = (PFNGLBEGINQUERYEXTPROC)
            eglGetProcAddress("glBeginQueryEXT");
        glEndQuery = (PFNGLENDQUERYEXTPROC)
            eglGetProcAddress("glEndQueryEXT");
        glGetQueryObjectuiv = (PFNGLGETQUERYOBJECTUIVEXTPROC)
            eglGetProcAddress("glGetQueryObjectuivEXT");
        glGetQueryObjectui64v = (PFNGLGETQUERYOBJECTUI64VEXTPROC)
            eglGetProcAddress("glGetQueryObjectui64vEXT");
        
        glGenQueries(QUERY_COUNT, queries);
        supported = true;
    }
    
    void BeginQuery(const char* name) {
        if (!supported) return;
        
        currentQuery = nextQuery;
        nextQuery = (nextQuery + 1) % QUERY_COUNT;
        currentName = name;
        
        glBeginQuery(GL_TIME_ELAPSED_EXT, queries[currentQuery]);
    }
    
    void EndQuery() {
        if (!supported) return;
        glEndQuery(GL_TIME_ELAPSED_EXT);
    }
    
    // 获取结果（可能需要等待）
    float GetQueryResultMs(int queryIndex) {
        if (!supported) return 0.0f;
        
        GLuint available = 0;
        glGetQueryObjectuiv(queries[queryIndex], 
                            GL_QUERY_RESULT_AVAILABLE, &available);
        
        if (!available) {
            return -1.0f;  // 未就绪
        }
```

```cpp
class AndroidHardwareBuffer {
public:
    // 创建HardwareBuffer
    bool Create(int width, int height) {
        AHardwareBuffer_Desc desc = {};
        desc.width = width;
        desc.height = height;
        desc.layers = 1;
        desc.format = AHARDWAREBUFFER_FORMAT_R8G8B8A8_UNORM;
        desc.usage = AHARDWAREBUFFER_USAGE_GPU_SAMPLED_IMAGE |
                     AHARDWAREBUFFER_USAGE_CPU_WRITE_OFTEN;
        
        int result = AHardwareBuffer_allocate(&desc, &buffer);
        if (result != 0) {
            LOG("Failed to allocate HardwareBuffer: %d", result);
            return false;
        }
        
        this->width = width;
        this->height = height;
        
        return true;
    }
    
    // CPU写入数据
    bool WritePixels(const void* pixels) {
        void* mappedPtr = nullptr;
        
        int result = AHardwareBuffer_lock(
            buffer,
            AHARDWAREBUFFER_USAGE_CPU_WRITE_OFTEN,
            -1,      // fence
            nullptr, // rect
            &mappedPtr
        );
        
        if (result != 0 || !mappedPtr) {
            LOG("Failed to lock HardwareBuffer: %d", result);
            return false;
        }
        
        // 获取stride
        AHardwareBuffer_Desc desc;
        AHardwareBuffer_describe(buffer, &desc);
        
        // 按行复制（考虑stride）
        const uint8_t* src = (const uint8_t*)pixels;
        uint8_t* dst = (uint8_t*)mappedPtr;
        int rowBytes = width * 4;
        int stride = desc.stride * 4;
        
        for (int y = 0; y < height; ++y) {
            memcpy(dst, src, rowBytes);
            src += rowBytes;
            dst += stride;
        }
        
        AHardwareBuffer_unlock(buffer, nullptr);
        return true;
    }
    
    // 转换为OpenGL纹理
    GLuint ConvertToGLTexture(EGLDisplay display) {
        // 获取EGLClientBuffer
        EGLClientBuffer clientBuffer = 
            eglGetNativeClientBufferANDROID(buffer);
        
        if (!clientBuffer) {
            LOG("Failed to get EGLClientBuffer");
            return 0;
        }
        
        // 创建EGLImage
        EGLint attribs[] = {
            EGL_IMAGE_PRESERVED_KHR, EGL_TRUE,
            EGL_NONE
        };
        
        EGLImage eglImage = eglCreateImageKHR(
            display,
            EGL_NO_CONTEXT,
            EGL_NATIVE_BUFFER_ANDROID,
            clientBuffer,
            attribs
        );
        
        if (eglImage == EGL_NO_IMAGE_KHR) {
            LOG("Failed to create EGLImage");
            return 0;
        }

        GLuint texture;
        glGenTextures(1, &texture);
        glBindTexture(GL_TEXTURE_2D, texture);
        
        // 绑定EGLImage到纹理
        glEGLImageTargetTexture2DOES(GL_TEXTURE_2D, eglImage);
        
        glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MIN_FILTER, GL_LINEAR);
        glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MAG_FILTER, GL_LINEAR);
        
        // 保存EGLImage引用
        this->eglImage = eglImage;
        this->glTexture = texture;
        
        return texture;
    }

            glDeleteTextures(1, &glTexture);
            glTexture = 0;
        }
        
        if (eglImage != EGL_NO_IMAGE_KHR) {
            eglDestroyImageKHR(eglGetCurrentDisplay(), eglImage);

            AHardwareBuffer_release(buffer);
            buffer = nullptr;
        }
    }

private:

    GLuint glTexture = 0;
```

```cpp
class ProducerConsumerBuffer {
public:
    void Initialize(size_t bufferSize) {
        for (int i = 0; i < 2; ++i) {
            glGenBuffers(1, &buffers[i]);
            glBindBuffer(GL_SHADER_STORAGE_BUFFER, buffers[i]);
            glBufferData(GL_SHADER_STORAGE_BUFFER, bufferSize,
                         nullptr, GL_DYNAMIC_COPY);
            fences[i] = nullptr;
        }
    }
    
    // CPU/Compute Shader写入
    GLuint GetWriteBuffer() {
        int writeIdx = writeIndex;
        
        // 等待该缓冲的读取完成
        if (fences[writeIdx]) {
            glClientWaitSync(fences[writeIdx], 
                            GL_SYNC_FLUSH_COMMANDS_BIT,
                            GL_TIMEOUT_IGNORED);
            glDeleteSync(fences[writeIdx]);
            fences[writeIdx] = nullptr;
        }
        
        return buffers[writeIdx];
    }
    
    // 完成写入，切换缓冲
    void FinishWrite() {
        writeIndex = 1 - writeIndex;
    }
    
    // GPU/渲染读取
    GLuint GetReadBuffer() {
        int readIdx = 1 - writeIndex;
        return buffers[readIdx];
    }
    
    // 完成读取，插入Fence
    void FinishRead() {
        int readIdx = 1 - writeIndex;
        fences[readIdx] = glFenceSync(GL_SYNC_GPU_COMMANDS_COMPLETE, 0);
    }
    
private:
    GLuint buffers[2];
    GLsync fences[2];
    int writeIndex = 0;
};

// 三缓冲流水线
class TripleBufferPipeline {
public:
    enum BufferState {
        STATE_FREE,      // 可写入
        STATE_PENDING,   // 等待GPU使用
        STATE_IN_USE     // GPU正在使用
    };
    
    struct Buffer {
        GLuint id;
        GLsync fence;
        BufferState state;
    };
    
    void Initialize(size_t bufferSize) {
        for (int i = 0; i < 3; ++i) {
            glGenBuffers(1, &buffers[i].id);
            glBindBuffer(GL_ARRAY_BUFFER, buffers[i].id);
            glBufferData(GL_ARRAY_BUFFER, bufferSize, nullptr, GL_STREAM_DRAW);
            buffers[i].fence = nullptr;
            buffers[i].state = STATE_FREE;
        }
    }
    
    // 获取可写入的缓冲
    int AcquireWriteBuffer() {
        // 首先尝试找到FREE状态的缓冲
        for (int i = 0; i < 3; ++i) {
            if (buffers[i].state == STATE_FREE) {
                buffers[i].state = STATE_PENDING;
                return i;
            }
        }
        
        // 检查PENDING缓冲的Fence
        for (int i = 0; i < 3; ++i) {
            if (buffers[i].state == STATE_IN_USE && buffers[i].fence) {
                GLint status;
                glGetSynciv(buffers[i].fence, GL_SYNC_STATUS, 1, nullptr, &status);
                
                if (status == GL_SIGNALED) {
                    glDeleteSync(buffers[i].fence);
                    buffers[i].fence = nullptr;
                    buffers[i].state = STATE_PENDING;
                    return i;
                }
            }
        }
        
        // 强制等待最旧的缓冲
        int oldest = FindOldestInUse();
        if (oldest >= 0 && buffers[oldest].fence) {
            glClientWaitSync(buffers[oldest].fence, 
                            GL_SYNC_FLUSH_COMMANDS_BIT,
                            GL_TIMEOUT_IGNORED);
            glDeleteSync(buffers[oldest].fence);
            buffers[oldest].fence = nullptr;
            buffers[oldest].state = STATE_PENDING;
            return oldest;
        }
        
        return -1;  // 错误状态
    }
    
    // 提交缓冲给GPU使用
    void SubmitForRendering(int index) {
        buffers[index].state = STATE_IN_USE;
        buffers[index].fence = glFenceSync(GL_SYNC_GPU_COMMANDS_COMPLETE, 0);
    }
    
private:
    Buffer buffers[3];
    
    int FindOldestInUse() {
        for (int i = 0; i < 3; ++i) {
            if (buffers[i].state == STATE_IN_USE) {
                return i;
            }
        }
        return -1;
    }
};
```

```cpp
            particles.end()
```

```cpp
        glGenTextures(1, &texture);
        glBindTexture(GL_TEXTURE_2D, texture);
        glTexImage2D(GL_TEXTURE_2D, 0, GL_RGBA8,
                     atlasWidth, atlasHeight, 0,
                     GL_RGBA, GL_UNSIGNED_BYTE, nullptr);
        
        glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MIN_FILTER, GL_LINEAR);
        glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_MAG_FILTER, GL_LINEAR);
        
        // 初始化PBO用于异步更新
        glGenBuffers(1, &pbo);
        glBindBuffer(GL_PIXEL_UNPACK_BUFFER, pbo);
        glBufferData(GL_PIXEL_UNPACK_BUFFER,
                     atlasWidth * atlasHeight * 4,
                     nullptr, GL_STREAM_DRAW);
    }
    
    // 添加或更新子纹理
    int AddOrUpdateRegion(const std::string& name, 
                          int width, int height,
                          const void* pixels) {
        Region* region;
        
        auto it = regionMap.find(name);
        if (it != regionMap.end()) {
            region = &regions[it->second];
        } else {
            // 分配新区域
            int id = AllocateRegion(width, height);
            if (id < 0) return -1;
            
            regionMap[name] = id;
            region = &regions[id];
        }
        
        // 标记为脏，添加到更新队列
        region->dirty = true;
        pendingUpdates.push_back({name, pixels, width, height});
        
        return regionMap[name];
    }
    
    // 批量更新（每帧调用一次）
    void FlushUpdates() {
        if (pendingUpdates.empty()) return;
        
        glBindBuffer(GL_PIXEL_UNPACK_BUFFER, pbo);
        glBindTexture(GL_TEXTURE_2D, texture);
        
        for (const auto& update : pendingUpdates) {
            auto it = regionMap.find(update.name);
            if (it == regionMap.end()) continue;
            
            Region& region = regions[it->second];
            
            // 映射PBO并写入数据
            void* mapped = glMapBufferRange(
                GL_PIXEL_UNPACK_BUFFER,
                0, update.width * update.height * 4,
                GL_MAP_WRITE_BIT | GL_MAP_INVALIDATE_BUFFER_BIT
            );
            
            if (mapped) {
                memcpy(mapped, update.pixels, update.width * update.height * 4);
                glUnmapBuffer(GL_PIXEL_UNPACK_BUFFER);
                
                // 更新纹理区域
                glTexSubImage2D(GL_TEXTURE_2D, 0,
                                region.x, region.y,
                                update.width, update.height,
                                GL_RGBA, GL_UNSIGNED_BYTE,
                                nullptr);
            }
            
            region.dirty = false;
        }
        
        glBindBuffer(GL_PIXEL_UNPACK_BUFFER, 0);
        pendingUpdates.clear();
    }
    
    GLuint GetTexture() const { return texture; }
    
private:
    struct PendingUpdate {
        std::string name;
        const void* pixels;
        int width, height;
    };
    
    int AllocateRegion(int w, int h) {
        // 简单的行分配算法
        // 实际应用中应使用更高效的装箱算法
        if (currentX + w > width) {
            currentX = 0;
            currentY += currentRowHeight;
            currentRowHeight = 0;
        }
        
        if (currentY + h > height) {
            return -1;  // 图集已满
        }
        
        Region region = {currentX, currentY, w, h, false};
        regions.push_back(region);
        
        currentX += w;
        currentRowHeight = std::max(currentRowHeight, h);
        
        return regions.size() - 1;
    }
    
    GLuint texture;
    GLuint pbo;
    int width, height;
    int currentX = 0, currentY = 0, currentRowHeight = 0;
    
    std::vector<Region> regions;
    std::unordered_map<std::string, int> regionMap;
    std::vector<PendingUpdate> pendingUpdates;
};
```

## 总结

数据同步优化是移动端渲染性能的关键环节。通过合理的缓冲管理、异步传输、零拷贝技术和精确的同步控制，可以显著减少CPU/GPU之间的等待时间。

**核心优化原则**：

1. **避免同步等待**
   - 使用多缓冲轮换
   - PBO异步传输
   - Fence细粒度控制

2. **减少数据拷贝**
   - 平台零拷贝API（HardwareBuffer/CVPixelBuffer）
   - glMapBufferRange直接映射
   - 压缩纹理格式

3. **正确的Usage Hints**
   - STATIC/DYNAMIC/STREAM正确选择
   - 与实际使用模式匹配

4. **平台适配**
   - 检测API级别和扩展
   - 提供降级方案

**优化决策树**：

```
数据类型？
├── 顶点/索引数据
│   ├── 静态 → VBO(STATIC_DRAW)
│   └── 动态 → RingBuffer + Orphaning
│
├── 纹理数据
│   ├── 静态 → 压缩格式一次上传
│   ├── 视频流 → HardwareBuffer/CVPixelBuffer
│   └── 动态更新 → PBO异步
│
├── Uniform数据
│   ├── 少量 → glUniform*
│   └── 大量 → UBO
│
└── 计算数据
    └── SSBO + Memory Barrier
```

通过综合运用本文档介绍的技术，可以构建高性能的移动端渲染系统，充分利用现代移动GPU的能力。
