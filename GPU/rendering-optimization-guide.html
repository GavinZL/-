一、概述

1.1 背景与意义

渲染优化是图形应用开发中的核心环节，直接影响用户体验、设备功耗和应用性能。随着移动设备的普及和高分辨率显示器的广泛应用，渲染性能优化变得越来越重要。一个优秀的渲染引擎不仅要能够渲染出精美的画面，更要在各种硬件平台上保持流畅的帧率。

2.2.3 瓶颈定位方法

技巧：分辨率测试法 降低渲染分辨率（如从1080p降到720p），如果帧率明显提升，说明是片段处理或ROP瓶颈；如果帧率无明显变化，则是CPU或顶点处理瓶颈。
技巧：着色器复杂度测试 简化片段着色器逻辑（如移除光照计算、纹理采样），观察性能变化。如果性能大幅提升，说明是片段着色器瓶颈。
技巧：几何复杂度测试 降低模型LOD或减少绘制的三角形数量。如果性能提升明显，说明是顶点处理或几何处理瓶颈。

2.3 性能分析实战流程

// 性能分析框架示例 (C++)
class PerformanceProfiler {
public:
    struct FrameStats {
        float cpuTime;
        float gpuTime;
        int drawCalls;
        int triangles;
        int stateChanges;
    };

    void BeginFrame() {
        cpuStartTime = GetCurrentTime();
        drawCalls = 0;
        triangles = 0;
        stateChanges = 0;
        
        // 启动GPU查询
        glBeginQuery(GL_TIME_ELAPSED, gpuTimeQuery);
    }

    void EndFrame() {
        glEndQuery(GL_TIME_ELAPSED);
        
        cpuTime = GetCurrentTime() - cpuStartTime;
        
        // 获取GPU时间（需要等待查询结果）
        GLuint64 elapsed;
        glGetQueryObjectui64v(gpuTimeQuery, GL_QUERY_RESULT, &elapsed);
        gpuTime = elapsed / 1000000.0f;
        
        // 记录统计
        LogFrameStats();
    }

    void RecordDrawCall(int triCount) {
        drawCalls++;
        triangles += triCount;
    }

    void RecordStateChange() {
        stateChanges++;
    }

    FrameStats GetStats() const {
        return {cpuTime, gpuTime, drawCalls, triangles, stateChanges};
    }

private:
    double cpuStartTime;
    float cpuTime, gpuTime;
    int drawCalls, triangles, stateChanges;
    GLuint gpuTimeQuery;
};

三、优化思想与原则

3.1 核心优化思想

3.1.1 降低工作量

  • 减少绘制内容：视锥剔除、遮挡剔除、LOD系统
  • 简化计算：降低着色器复杂度、使用查找表（LUT）
  • 合并批次：减少Draw Call、使用实例化渲染

3.1.2 提高效率

  • 并行计算：充分利用GPU的并行特性
  • 缓存友好：优化数据布局，提高缓存命中率
  • 异步处理：使用异步计算、资源流式加载

3.1.3 优化内存访问

  • 减少带宽消耗：纹理压缩、降低精度
  • 优化内存布局：结构体对齐、数组紧凑
  • 重用资源：对象池、纹理图集

3.2 优化原则

原则1：测量优先 在优化之前先测量，确定真正的瓶颈。不要基于猜测进行优化。
原则2：二八定律 80%的性能问题通常来自20%的代码。集中精力优化关键热点。
原则3：平衡优化 避免过度优化某一方面导致其他瓶颈。追求整体平衡。
原则4：可维护性 优化不应显著降低代码可读性和维护性。优先选择简单有效的方案。

3.3 优化策略矩阵

瓶颈类型 主要症状 优化方向 优先级
CPU瓶颈 GPU利用率低，CPU占用高 减少Draw Call、批处理、多线程 高
顶点处理 降低分辨率性能不变，减少三角形性能提升 LOD、简化模型、顶点着色器优化 中
片段处理 降低分辨率性能提升明显 Early-Z、减少overdraw、简化着色器 高
纹理采样 移除纹理采样性能大幅提升 纹理压缩、Mipmap、减少采样次数 中
带宽 内存带宽占用高 降低精度、压缩、减少RenderTarget尺寸 高

四、CPU端优化

4.1 Draw Call优化

4.1.1 批处理 (Batching)

将多个使用相同材质和纹理的对象合并为一个Draw Call。

// 静态批处理示例 (OpenGL)
struct StaticBatch {
    GLuint vao, vbo;
    int vertexCount;
    Material* material;
};

void CreateStaticBatch(const std::vector<Mesh*>& meshes) {
    std::vector<Vertex> combinedVertices;
    
    // 合并顶点数据
    for (auto mesh : meshes) {
        combinedVertices.insert(
            combinedVertices.end(),
            mesh->vertices.begin(),
            mesh->vertices.end()
        );
    }
    
    // 创建合并后的VBO
    glGenVertexArrays(1, &batch.vao);
    glGenBuffers(1, &batch.vbo);
    
    glBindVertexArray(batch.vao);
    glBindBuffer(GL_ARRAY_BUFFER, batch.vbo);
    glBufferData(GL_ARRAY_BUFFER, 
                 combinedVertices.size() * sizeof(Vertex),
                 combinedVertices.data(), 
                 GL_STATIC_DRAW);
    
    // 设置顶点属性...
    batch.vertexCount = combinedVertices.size();
}

void RenderBatch(const StaticBatch& batch) {
    batch.material->Bind();
    glBindVertexArray(batch.vao);
    glDrawArrays(GL_TRIANGLES, 0, batch.vertexCount);
}

4.1.2 实例化渲染 (Instancing)

使用一次Draw Call绘制多个相同模型的不同实例。

// GPU实例化 (OpenGL)
struct InstanceData {
    glm::mat4 modelMatrix;
    glm::vec4 color;
};

void SetupInstancing(GLuint vao, const std::vector<InstanceData>& instances) {
    GLuint instanceVBO;
    glGenBuffers(1, &instanceVBO);
    
    glBindVertexArray(vao);
    glBindBuffer(GL_ARRAY_BUFFER, instanceVBO);
    glBufferData(GL_ARRAY_BUFFER, 
                 instances.size() * sizeof(InstanceData),
                 instances.data(), 
                 GL_STATIC_DRAW);
    
    // 设置实例属性（模型矩阵）
    for (int i = 0; i < 4; i++) {
        glEnableVertexAttribArray(3 + i);
        glVertexAttribPointer(3 + i, 4, GL_FLOAT, GL_FALSE, 
                              sizeof(InstanceData),
                              (void*)(sizeof(glm::vec4) * i));
        glVertexAttribDivisor(3 + i, 1); // 每个实例更新一次
    }
    
    // 设置颜色属性
    glEnableVertexAttribArray(7);
    glVertexAttribPointer(7, 4, GL_FLOAT, GL_FALSE,
                          sizeof(InstanceData),
                          (void*)(sizeof(glm::mat4)));
    glVertexAttribDivisor(7, 1);
}

void RenderInstanced(GLuint vao, int vertexCount, int instanceCount) {
    glBindVertexArray(vao);
    glDrawArraysInstanced(GL_TRIANGLES, 0, vertexCount, instanceCount);
}

// 间接绘制 (OpenGL 4.3+)
struct DrawElementsIndirectCommand {
    GLuint count;         // 索引数量
    GLuint instanceCount; // 实例数量
    GLuint firstIndex;    // 第一个索引
    GLuint baseVertex;    // 基础顶点偏移

};

void MultiDrawIndirect() {
    std::vector<DrawElementsIndirectCommand> commands;
    
    // 填充绘制命令
    for (auto& object : visibleObjects) {
        commands.push_back({
            object.indexCount,
            object.instanceCount,
            object.firstIndex,
            object.baseVertex,
            object.baseInstance
        });
    }
    
    // 上传命令缓冲
    GLuint indirectBuffer;
    glGenBuffers(1, &indirectBuffer);
    glBindBuffer(GL_DRAW_INDIRECT_BUFFER, indirectBuffer);
    glBufferData(GL_DRAW_INDIRECT_BUFFER,
                 commands.size() * sizeof(DrawElementsIndirectCommand),
                 commands.data(),
                 GL_DYNAMIC_DRAW);
    
    // 一次绘制所有对象
    glMultiDrawElementsIndirect(GL_TRIANGLES,
                                GL_UNSIGNED_INT,
                                0,
                                commands.size(),
                                0);
}

4.2 剔除优化

4.2.1 视锥剔除 (Frustum Culling)

// 视锥剔除实现
struct Plane {
    glm::vec3 normal;
    float distance;
    
    float DistanceToPoint(const glm::vec3& point) const {
        return glm::dot(normal, point) + distance;
    }
};

struct Frustum {
    Plane planes[6]; // Left, Right, Bottom, Top, Near, Far
    
    void ExtractFromMatrix(const glm::mat4& vpMatrix) {
        // 左平面
        planes[0].normal = glm::vec3(vpMatrix[0][3] + vpMatrix[0][0],
                                     vpMatrix[1][3] + vpMatrix[1][0],
                                     vpMatrix[2][3] + vpMatrix[2][0]);
        planes[0].distance = vpMatrix[3][3] + vpMatrix[3][0];
        
        // ...其他平面类似提取...
        
        // 归一化平面
        for (int i = 0; i < 6; i++) {
            float len = glm::length(planes[i].normal);
            planes[i].normal /= len;
            planes[i].distance /= len;
        }
    }
    
    bool IsBoxVisible(const glm::vec3& minBounds, const glm::vec3& maxBounds) const {
        for (int i = 0; i < 6; i++) {
            // 计算正顶点（最远点）
            glm::vec3 positiveVertex = minBounds;
            if (planes[i].normal.x >= 0) positiveVertex.x = maxBounds.x;
            if (planes[i].normal.y >= 0) positiveVertex.y = maxBounds.y;
            if (planes[i].normal.z >= 0) positiveVertex.z = maxBounds.z;
            
            // 如果正顶点在平面外侧，则整个盒子在外侧
            if (planes[i].DistanceToPoint(positiveVertex) < 0) {
                return false;
            }
        }
        return true;
    }
};

4.2.2 遮挡剔除 (Occlusion Culling)

// 硬件遮挡查询 (OpenGL)
class OcclusionQuery {
public:
    OcclusionQuery() {
        glGenQueries(1, &queryId);
    }
    
    void BeginQuery() {
        glBeginQuery(GL_ANY_SAMPLES_PASSED, queryId);
    }
    
    void EndQuery() {
        glEndQuery(GL_ANY_SAMPLES_PASSED);
    }
    
    bool IsVisible() {
        GLuint result;
        glGetQueryObjectuiv(queryId, GL_QUERY_RESULT, &result);
        return result > 0;
    }
    
    bool IsResultAvailable() {
        GLuint available;
        glGetQueryObjectuiv(queryId, GL_QUERY_RESULT_AVAILABLE, &available);
        return available == GL_TRUE;
    }
    
private:
    GLuint queryId;
};

// 两帧延迟的遮挡剔除
void RenderWithOcclusionCulling() {
    for (auto& object : objects) {
        // 检查上一帧的查询结果
        if (object.query.IsResultAvailable()) {
            object.wasVisible = object.query.IsVisible();
        }
        
        // 如果上一帧可见，开始新的查询
        if (object.wasVisible) {
            // 先绘制边界盒进行遮挡测试
            glColorMask(GL_FALSE, GL_FALSE, GL_FALSE, GL_FALSE);
            glDepthMask(GL_FALSE);
            
            object.query.BeginQuery();
            RenderBoundingBox(object.bounds);
            object.query.EndQuery();
            
            glColorMask(GL_TRUE, GL_TRUE, GL_TRUE, GL_TRUE);
            glDepthMask(GL_TRUE);
            
            // 绘制实际物体
            RenderObject(object);
        }
    }
}

4.3 LOD系统

// 基于距离的LOD系统
struct LODLevel {
    Mesh* mesh;
    float distance;  // 切换距离
};

class LODObject {
public:
    std::vector<LODLevel> lodLevels;
    glm::vec3 position;
    
    Mesh* SelectLOD(const glm::vec3& cameraPos) {
        float distance = glm::distance(position, cameraPos);
        
        for (size_t i = 0; i < lodLevels.size(); i++) {
            if (distance < lodLevels[i].distance || i == lodLevels.size() - 1) {
                return lodLevels[i].mesh;
            }
        }
        return nullptr;
    }
};

// 屏幕空间误差LOD
int SelectLODByScreenSize(float objectRadius, float distance, float fov, int screenHeight) {
    // 计算对象在屏幕上的像素大小
    float screenSize = (objectRadius / distance) * (2.0f * tan(fov / 2.0f)) * screenHeight;
    
    if (screenSize > 200) return 0;      // 高精度LOD
    else if (screenSize > 100) return 1; // 中精度LOD
    else if (screenSize > 50) return 2;  // 低精度LOD
    else return 3;                      // 最低精度LOD或billboard
}

4.4 多线程优化

// 多线程命令缓冲生成 (Vulkan风格)
void RecordCommandBuffersMultithreaded() {
    const int threadCount = std::thread::hardware_concurrency();
    std::vector<std::thread> threads;
    
    // 将对象分配给不同线程
    int objectsPerThread = objects.size() / threadCount;
    
    for (int i = 0; i < threadCount; i++) {
        threads.emplace_back([this, i, objectsPerThread]() {
            int start = i * objectsPerThread;
            int end = (i == threadCount - 1) ? objects.size() : (i + 1) * objectsPerThread;
            
            // 每个线程记录自己的命令缓冲
            auto cmdBuffer = secondaryCommandBuffers[i];
            cmdBuffer.Begin();
            
            for (int j = start; j < end; j++) {
                if (IsVisible(objects[j])) {
                    RecordDrawCommands(cmdBuffer, objects[j]);
                }
            }
            
            cmdBuffer.End();
        });
    }
    
    // 等待所有线程完成
    for (auto& thread : threads) {
        thread.join();
    }
    
    // 主线程执行所有次级命令缓冲
    primaryCommandBuffer.ExecuteCommands(secondaryCommandBuffers);
}

5.2.2 减少Overdraw

// 渲染顺序优化
void RenderScene() {
    // 1. 先渲染不透明物体，从前到后排序
    SortObjectsFrontToBack(opaqueObjects);
    for (auto& obj : opaqueObjects) {
        RenderObject(obj);
    }
    
    // 2. 渲染天空盒（深度测试为EQUAL，避免重复绘制）
    glDepthFunc(GL_LEQUAL);
    RenderSkybox();
    glDepthFunc(GL_LESS);
    
    // 3. 最后渲染透明物体，从后到前排序
    SortObjectsBackToFront(transparentObjects);
    for (auto& obj : transparentObjects) {
        RenderObject(obj);
    }
}

九、平台特定优化

9.1 移动端优化 (iOS/Android)

9.1.1 降低功耗

  • 降低帧率：不需要60fps时使用30fps，节省电池
  • 动态分辨率：根据负载动态调整渲染分辨率
  • 避免过度绘制：Overdraw是移动GPU的主要功耗来源
  • 优化着色器：移动GPU计算能力有限，简化着色器逻辑

9.1.2 Tile-Based Rendering优化

移动GPU（PowerVR, Mali, Adreno）多采用Tile-Based Deferred Rendering (TBDR)架构：

// TBDR优化技巧
void OptimizeForTBDR() {
    // 1. 避免RenderPass中间读取attachment
    // 不好：会导致tile内存flush
    glBindFramebuffer(GL_FRAMEBUFFER, fbo);
    RenderScene();
    glBindTexture(GL_TEXTURE_2D, fbo_color);  // 避免这样做!
    
    // 2. 使用glInvalidateFramebuffer丢弃不需要的数据
    GLenum attachments[] = {GL_DEPTH_ATTACHMENT, GL_STENCIL_ATTACHMENT};
    glInvalidateFramebuffer(GL_FRAMEBUFFER, 2, attachments);
    
    // 3. 使用glDiscardFramebufferEXT（OpenGL ES 2.0）
    glDiscardFramebufferEXT(GL_FRAMEBUFFER, 2, attachments);
}

9.2 PC端优化 (Windows/Linux/macOS)

9.2.1 多线程渲染

// DirectX 12 / Vulkan 多线程命令录制
void MultiThreadedRendering() {
    const int threadCount = std::thread::hardware_concurrency();
    std::vector<std::thread> threads;
    
    for (int i = 0; i < threadCount; i++) {
        threads.emplace_back([i, threadCount]() {
            // 每个线程录制自己的命令缓冲
            auto cmdBuffer = commandBuffers[i];
            cmdBuffer->Begin();
            
            // 分配工作
            int start = i * (objectCount / threadCount);
            int end = (i + 1) * (objectCount / threadCount);
            
            for (int j = start; j < end; j++) {
                RecordDrawCommands(cmdBuffer, objects[j]);
            }
            
            cmdBuffer->End();
        });
    }
    
    for (auto& t : threads) t.join();
}

十、最佳实践总结

开发阶段
从一开始就进行性能测量
为不同平台设定明确的性能目标
使用profiling工具定期检查
设计阶段
选择适合目标平台的技术方案
预留性能裕量（不要跑满资源）
考虑可扩展性和动态调整
优化阶段
先优化最明显的瓶颈
每次只优化一个方面
优化前后都要测量验证

10.1 快速检查清单

类别 检查项 目标
Draw Calls 是否进行了批处理和实例化？ < 2000 (移动端)
纹理 是否使用了压缩和Mipmap？ 100% 压缩
着色器 是否移除了不必要的计算？ 越简单越好
几何体 是否实现了LOD系统？ 3-5个LOD级别
剔除 是否实现视锥和遮挡剔除？ 剔除率>30%
内存 是否有资源流式加载？ VRAM使用<70%

10.2 常见错误

错误1：过早优化 在功能未完成前就开始优化，导致代码复杂度增加而收益不明显。
错误2：盲目优化 没有通过profiling确定瓶颈就开始优化，浪费时间在非关键路径上。
错误3：忽略平台差异 在PC上优化的方案不一定适用于移动端，需要针对不同平台调整。
错误4：过度优化 为了极致性能牺牲代码可维护性，得不偿失。
