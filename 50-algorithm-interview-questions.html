T001

两数之和

简单 ⭐⭐⭐⭐⭐
数组 哈希表 LeetCode 1
查看详细内容

题目描述

给定一个整数数组 nums 和一个整数目标值 target，请你在该数组中找出和为目标值 target 的那两个整数，并返回它们的数组下标。

说明：你可以假设每种输入只会对应一个答案。但是，数组中同一个元素在答案里不能重复出现。你可以按任意顺序返回答案。

示例 1：

输入：nums = [2,7,11,15], target = 9

输出：[0,1]

解释：因为 nums[0] + nums[1] == 9，返回 [0, 1]。

示例 2：

输入：nums = [3,2,4], target = 6

输出：[1,2]

数据范围：

  • 2 ≤ nums.length ≤ 10⁴
  • -10⁹ ≤ nums[i] ≤ 10⁹
  • -10⁹ ≤ target ≤ 10⁹
  • 只会存在一个有效答案

解题分析

问题理解：

本题的核心是在数组中找到两个数，使它们的和等于目标值。最直观的做法是双层循环遍历所有可能的组合，但这样时间复杂度为 O(n²)。我们需要优化。

优化思路：

关键在于：当我们遍历到元素 x 时，我们需要快速查找数组中是否存在 target - x。哈希表可以将查找时间优化到 O(1)。

最优解方案：

  1. 创建一个哈希表用于存储「值 → 索引」的映射
  2. 遍历数组，对于每个元素 nums[i]：
    • 计算补数 complement = target - nums[i]
    • 在哈希表中查找 complement 是否存在
    • 如果存在，返回 [哈希表中的索引, i]
    • 如果不存在，将 nums[i] 及其索引 i 存入哈希表
复杂度类型 复杂度 说明
时间复杂度 O(n) 只需遍历数组一次，哈希表查找为 O(1)
空间复杂度 O(n) 最坏情况需要存储 n 个元素到哈希表

算法步骤（伪代码）

函数 twoSum(nums, target):
    // 创建哈希表存储 值→索引 映射
    创建空哈希表 map
    
    // 遍历数组
    对于 i 从 0 到 nums.length-1:
        当前值 = nums[i]
        补数 = target - 当前值
        
        // 检查补数是否已存在
        如果 map 中存在 补数:
            返回 [map[补数], i]
        
        // 将当前值存入哈希表
        map[当前值] = i
    
    // 题目保证有解，不会执行到这里
    返回 空数组

算法流程图

graph TD A[开始] --> B[创建哈希表 map] B --> C[遍历数组元素 nums_i] C --> D[计算补数 = target - nums_i] D --> E{哈希表中是否存在补数?} E -->|是| F[返回 哈希表中补数的索引, i] E -->|否| G[将 nums_i, i 存入哈希表] G --> H{是否遍历完毕?} H -->|否| C H -->|是| I[返回结果]

T002

三数之和

中等 ⭐⭐⭐⭐⭐
数组 双指针 排序 LeetCode 15
查看详细内容

题目描述

给你一个包含 n 个整数的数组 nums，判断是否存在三个元素 a, b, c，使得 a + b + c = 0？请找出所有和为 0 且不重复的三元组。

注意：答案中不可以包含重复的三元组。

示例 1：

输入：nums = [-1,0,1,2,-1,-4]

输出：[[-1,-1,2],[-1,0,1]]

示例 2：

输入：nums = []

输出：[]

解题分析

问题理解：

相比两数之和，三数之和的难点在于需要去重。暴力解法需要三层循环，时间复杂度为 O(n³)。

优化思路：

  1. 先对数组排序，这样可以方便去重和使用双指针
  2. 固定一个数 nums[i]，问题转化为在剩余数组中找两个数，使它们的和为 -nums[i]
  3. 使用双指针从两端向中间靠拢，找到所有符合条件的组合
复杂度类型 复杂度 说明
时间复杂度 O(n²) 排序 O(n log n) + 外层循环 O(n) * 内层双指针 O(n)
空间复杂度 O(log n) 排序所需空间（不算输出数组）

算法步骤（伪代码）

函数 threeSum(nums):
    结果数组 = []
    如果 nums 长度 < 3:
        返回 结果数组
    
    // 排序数组
    对 nums 进行升序排序
    
    // 固定第一个数
    对于 i 从 0 到 nums.length-3:
        // 优化：如果最小值大于0，直接跳出
        如果 nums[i] > 0:
            跳出循环
        
        // 去重：跳过重复的值
        如果 i > 0 且 nums[i] == nums[i-1]:
            继续下一次循环
        
        // 双指针找另外两个数
        左指针 = i + 1
        右指针 = nums.length - 1
        
        当 左指针 < 右指针:
            和 = nums[i] + nums[左指针] + nums[右指针]
            
            如果 和 == 0:
                将 [nums[i], nums[左指针], nums[右指针]] 添加到结果数组
                
                // 去重：跳过重复值
                当 左指针 < 右指针 且 nums[左指针] == nums[左指针+1]:
                    左指针++
                当 左指针 < 右指针 且 nums[右指针] == nums[右指针-1]:
                    右指针--
                
                左指针++
                右指针--
            否则如果 和 < 0:
                左指针++
            否则:
                右指针--
    
    返回 结果数组

T003

合并两个有序数组

简单 ⭐⭐⭐⭐
数组 双指针 LeetCode 88
查看详细内容

题目描述

给你两个按 非递减顺序 排列的整数数组 nums1 和 nums2，另有两个整数 m 和 n，分别表示 nums1 和 nums2 中的元素数目。请你 合并 nums2 到 nums1 中，使合并后的数组同样按 非递减顺序 排列。

示例：

输入：nums1 = [1,2,3,0,0,0], m = 3, nums2 = [2,5,6], n = 3

输出：[1,2,2,3,5,6]

解题分析

优化思路：从后向前填充，避免元素覆盖。使用三个指针：p1指向nums1的有效元素末尾，p2指向nums2末尾，tail指向nums1的总末尾。

复杂度值
时间O(m+n)
空间O(1)

T007

反转链表

简单 ⭐⭐⭐⭐⭐
链表 迭代 递归 LeetCode 206
查看详细内容

题目描述

给你单链表的头节点 head，请你反转链表，并返回反转后的链表。

示例：

输入：head = [1,2,3,4,5]

输出：[5,4,3,2,1]

解题分析

迭代法：使用三个指针 prev, curr, next，遍历链表逐个反转指针方向。

复杂度值
时间O(n)
空间O(1)

算法步骤

函数 reverseList(head):
    prev = null
    curr = head
    
    当 curr 不为空:
        next = curr.next
        curr.next = prev
        prev = curr
        curr = next
    
    返回 prev

T015

二叉树的前序遍历

简单 ⭐⭐⭐⭐
二叉树递归栈LeetCode 144
查看详细内容

题目描述

给你二叉树的根节点 root，返回它节点值的 前序 遍历。

解题分析

递归法：根-左-右顺序访问。迭代法：使用栈模拟递归过程。

算法步骤

函数 preorderTraversal(root):
    结果 = []
    
    函数 traverse(node):
        如果 node 为空:
            返回
        结果.add(node.val)  // 根
        traverse(node.left)    // 左
        traverse(node.right)   // 右
    
    traverse(root)
    返回 结果
